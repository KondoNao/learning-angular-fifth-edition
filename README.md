# Global installation commands

## Installs the TypeScript compiler globally so you can use the `tsc` command.

```
npm install -g typescript
```

## Installs the TypeScript compiler and Node.js type definitions globally.
 - Note: Projects usually need `@types/node` installed locally.

```
npm install -g typescript @types/node
```

## Installs Angular CLI version 19 globally so you can use the `ng` command.

```
npm install -g @angular/cli@19
```
